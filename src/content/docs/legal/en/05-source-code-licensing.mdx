## 2. Proprietary Core Infrastructure

The server runtimes, intelligent routing backends, zero-latency key vault architectures, and financial ledger transaction pipelines are strictly closed-source, proprietary intellectual property of **ViralLinkUp Limited**. No rights of distribution, on-premises deployment, or source replication are conveyed except under an executed Enterprise Dedicated On-Premise Addendum.

---

## 3. Client Integration SDKs

- Official software development kits (SDKs) and integration connectors distributed via package managers are licensed under the standard **MIT License**.
- Developers and enterprises may integrate these libraries into commercial software without royalties, conditioned upon maintaining original copyright and attribution notices.

---

## 4. Open Source Governance & Attributions

Perplexta utilizes trusted open-source frameworks (including React, Tailwind CSS, Lucide, and Express). ViralLinkUp Limited strictly adheres to upstream open-source attribution mandates:
- All upstream copyrights and license notices remain intact within deployed dependencies.
- Open-source components are audited continuously for copyleft contamination, ensuring that customer application codebases remain entirely proprietary and unencumbered.
